Open agentic website
This site publishes its agent network (agent-manifest.json, network), so any agentic site can load it, following the Worldwide Agentic Web spec.

      
Private by construction
The website tools only ever return the redacted copy. Placeholders like [NAME 1] go to the agents; your real details stay in this page.

      
On-device inference
An OpenAI-compatible router that runs on Chrome's built-in Gemini Nano (nano-router.js). Other visitors can bring their own key.
